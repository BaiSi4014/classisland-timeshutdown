# TimeShutdown

一款 ClassIsland 插件 —— 为电教员 / 老师提供方便。

**用处：** 用户可以通过设置时间和循环次数来进行定时的关机，为电教员或老师下课、放学“跑路”提供方便。

**图标设计：** 哔哩哔哩「白汐BaiSi」（[白汐BaiSi的个人空间](https://space.bilibili.com/)）。图标中人物为原创 OC，白汐BaiSi 版权所有。

**制作说明：** 本插件的全部代码均由 AI 编写生成。作者仅负责需求设计 / 测试 / 发布以及图标设计，整体插件均由 AI（Agent）生成。使用前请自行评估代码质量与安全性。

## 功能

- 使用 ClassIsland 的 `IExactTimeService.GetCurrentLocalDateTime()` 获取时间，而不是用系统时间作为调度依据。
- 支持 `00:00:00` 到 `23:59:59` 的 24 小时制时间，精确到秒。
- 时间输入只需选择“时 / 分 / 秒”三个下拉框，不需要用户输入冒号。
- 支持仅一次、每天、每周指定星期几、每隔 N 天四种循环方式；“每 N 天”以创建任务当天为起点，切换到该模式或修改间隔时会以保存当天重新起算。
- 任务可以启用、停用、编辑和删除，配置会保存到 ClassIsland 为插件分配的 `PluginConfigFolder`。
- 到达任务时间后执行 `shutdown.exe /s /t 0`，效果等同于 `shutdown /s /t 0`。
- 仅一次任务默认从创建任务当天开始计算；例如 9 月 25 日 14:00 创建 20:00 的任务会在当天 20:00 执行，如果创建时已经过了 20:00，则顺延到次日 20:00。

## 构建

项目使用 .NET 8 SDK 和 `ClassIsland.PluginSdk` 2.0.4（面向 ClassIsland 2.x）：

```powershell
dotnet restore
dotnet build -c Release
```

构建成功后，`bin\Release\net8.0` 中的 DLL、`manifest.yml`、`README.md` 和 `icon.png` 就是插件文件。可以将整个输出目录作为插件目录加载，也可以按 ClassIsland 的插件安装方式打包为 `.cipx`。

项目默认关闭 SDK 的 CIPX 自动打包，因为 SDK 的打包目标依赖 PowerShell 7 (`pwsh`)。如果本机已安装 PowerShell 7，可以在命令行传入 `-p:CreateCipx=true`，或者将输出目录手动压缩为 ZIP 后改名为 `.cipx`。

## 使用

1. 将插件加载到 ClassIsland。
2. 打开“应用设置”中的“定时关机”页面。
3. 点击“新增任务”，填写名称、24 小时制时间、循环方式并保存。默认时间是创建任务时的当天时刻，时间已过会顺延 1 分钟，保证新建的仅一次任务属于创建当天。
4. 任务列表中的启用开关可以暂停或恢复任务；“编辑”和“删除”分别用于修改和移除任务。

## 重要说明

- 本插件的全部代码均由 AI 生成，作者仅负责需求设计 / 测试 / 发布与图标设计。使用前请自行评估代码质量与安全性。
- 关机命令会立即关闭电脑，请确认时间后启用任务。
- 到期状态会先保存到配置文件，再执行关机命令；如果系统命令返回异常，为避免重复发起关机，任务不会自动重试，可编辑或重新启用任务后再测试。
- 插件在 ClassIsland 运行期间每秒检查一次 ClassIsland 时间；电脑休眠期间无法执行命令，恢复运行后若任务已到期会补执行。
- 插件启动时不会补执行已经错过的一次性任务；循环任务会重新计算到下一个未来时间，避免用户打开电脑后被意外关机。
- 任务服务在插件退出时停止，不会自行驻留后台进程。

## 调度逻辑

调度器只处理已启用的任务。每个任务保存 `NextRunAt`：

- 一次性任务执行后自动关闭并清除下一次执行时间。
- 循环任务执行后自动计算下一次时间。
- 编辑、启用或停用任务时立即重新计算并保存状态。
